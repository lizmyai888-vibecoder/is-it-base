# Privacy Policy — Is it Base?

**Last updated:** November 2026

## What this extension does

Is it Base? is a browser extension that detects whether a website was built using Base44 or another vibe-coding platform.

## Data collection

**This extension collects no user data.**

All detection runs entirely within your browser. Nothing is transmitted to any external server.

Specifically:
- No browsing history is collected or stored
- No personal information is collected
- No data is sent to any server
- No cookies are set by this extension
- All analysis is local and temporary — results exist only while the popup is open

## Permissions used

| Permission | Why it is needed |
|---|---|
| `activeTab` | To access the current tab when you click the extension icon |
| `scripting` | To inject a detection script into the active tab |
